# Contributing to ResearchRadar

Thank you for your interest in contributing to ResearchRadar!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your feature or bugfix
4. Make your changes
5. Run tests and linting
6. Submit a pull request

## Development Setup

See the main README.md for environment setup instructions.

## Code Standards

- Follow PEP 8 for Python code
- Use ESLint/Prettier for JavaScript/React code
- Write tests for new features
- Update documentation as needed
- Keep commits atomic and write clear commit messages

## Open Source Requirements

- All dependencies must have permissive licenses (MIT, Apache-2.0, BSD)
- No AGPL/GPL dependencies
- All models must be open-weight with permissive licenses
- Test data must be openly licensed (arXiv, PubMed Central OA, CC-BY/CC0)
- Document licenses in `docs/OPEN_SOURCE_LICENSES.md` and `tests/fixtures/DATA_LICENSES.md`

## Pull Request Process

1. Update documentation if needed
2. Ensure all tests pass
3. Update IMPLEMENTATION_LOG.md with changes
4. Request review from maintainers

## Questions?

Open an issue for questions or discussion.
